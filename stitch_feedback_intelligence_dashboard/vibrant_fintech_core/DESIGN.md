## Brand & Style

This design system delivers a modern, high-conviction fintech experience engineered for retail investors, wealth builders, and quantitative traders. It strikes an intentional balance between institutional precision and consumer accessibility. The aesthetic marries crisp corporate structure with subtle modern glassmorphism and tactile feedback, eliminating the friction and opacity typical of legacy financial platforms.

### Aesthetic Principles
- **Clarity over Density:** Data density is balanced with breathing room. Financial instruments and metrics are arranged with strict visual hierarchies so high-stakes information is digestible at a glance.
- **Glass-Infused Elevation:** Subtle translucent backdrops with frosted blurs are applied to elevated navigation bars, sticky action bars, and modal surfaces, grounding the interface in a modern multi-plane canvas.
- **Semantic Fidelity:** Color is never purely decorative; it communicates real-time performance, signal polarity, and asset distribution with zero ambiguity.
- **Refined Materiality:** Delicate 1px structural outlines and gentle ambient shadows frame containers cleanly against muted off-white surfaces, avoiding harsh high-contrast dividers.

## Colors

The palette is tuned specifically for light-mode clarity, high dynamic range financial readouts, and immediate signal classification.

### Core Roles
- **Primary (`#00D09C` / `#00B386`):** Vibrant Emerald Teal. Represents portfolio wealth growth, affirmative financial actions (Buy, Invest, Confirm), and brand identity. Deep emerald `#00B386` is leveraged for high-contrast interactive states and solid button hover profiles.
- **Secondary (`#5367FF`):** Deep Electric Indigo. Reserved for quantitative algorithms, automated portfolios, intelligent discovery, and predictive machine-learning insights.
- **Tertiary (`#FFB020`):** Warm Amber. Dictates caution, pending settlements, mid-tier risk assets, and market hold advisories.
- **Critical / Negative (`#EB5757`):** Crimson Coral. Reserved strictly for capital drawdown, daily losses, sell prompts, and critical system anomalies.

### Surface & Border Architecture
- **Surface Canvas (`#F7F9FB`):** Soft, cool off-white neutral base that mitigates screen glare during extended trading hours.
- **Surface Card / Container (`#FFFFFF`):** Pure white container canvas providing maximum contrast for metric figures and data charts.
- **Glass Overlay Surfaces (`rgba(255, 255, 255, 0.75)`):** Translucent backdrop for navigation, sheet trays, and floating summary pills.
- **Borders & Dividers (`#E8ECF2`):** Ultra-refined boundary line for cards, modular slots, and data-grid cells.
- **Subtle Row Separators (`#F0F3F7`):** Non-intrusive internal table lines.

### Text & Contrast Hierarchy
- **Primary Text (`#1E222B`):** Deep charcoal slate delivering AAA-grade readability for asset values and headers without the harshness of pure `#000000`.
- **Secondary Text (`#44475B`):** Muted slate for subheaders, table headers, column labels, and timestamp metadata.
- **Tertiary Text (`#7E8597`):** Inactive indicators, ticker codes, and helper descriptors.

## Typography

The type system is a deliberate pairing: **Plus Jakarta Sans** for headlines, display amounts, and metric units provides an approachable, geometric presence. **Inter** handles high-density tabular records, lists, form elements, and analytical commentary with neutral legibility.

### Numerical Representation
- All portfolio values, index points, percentage deltas, and timestamp values must be rendered using `font-variant-numeric: tabular-nums lining-nums`. This prevents layout shifts across dynamic ticker feeds and ticker carousels.
- Currency symbols (`$`, `₹`, `€`) match their adjacent numeric font scale but carry a `400` or `500` weight to keep emphasis focused on the numeric value.

## Layout & Spacing

The layout is grounded in an 8-point base scale with 4-point micro increments (`space-2xs` = 4px, `space-xs` = 8px) for compact card designs and financial data tables.

### Grid Architecture
- **Desktop (1024px+):** 12-column responsive fluid grid. 24px (`space-xl`) gutters, 32px (`space-2xl`) outer margin, maximum content container width of 1280px.
- **Tablet (768px - 1023px):** 8-column layout. 16px (`space-md`) gutters, 24px (`space-xl`) outer margins.
- **Mobile (< 768px):** 4-column layout. 12px (`space-sm`) gutters, 16px (`space-md`) screen padding.

### Financial Density & Layout Behaviors
- **Dashboard Layouts:** Multi-column view on desktop features a 60/40 or 70/30 split between core chart/portfolio metrics and secondary execution/order books.
- **Reflow Logic:** On screens narrower than 1024px, right-rail order forms collapse into persistent bottom sheets or sticky action bars with backdrop blurs.
- **Vertical Spacing:** Component groups are separated by `space-2xl` (32px), while internal card modules and data lists maintain tight groupings of `space-sm` (12px) to `space-md` (16px).

## Elevation & Depth

Visual hierarchy uses a refined multi-layer system: crisp structural boundaries, low-diffusion shadows tinted with dark slate, and frosted glass elements for interactive chrome.

### Surface Tiers
1. **Tier 0 (Canvas Base):** Flat `#F7F9FB`. Holds the root application viewport.
2. **Tier 1 (Resting Cards):** Solid `#FFFFFF` enclosed by a 1px continuous outline in `#E8ECF2`. Shadow: `0px 1px 3px rgba(30, 34, 43, 0.04), 0px 4px 12px rgba(30, 34, 43, 0.02)`.
3. **Tier 2 (Hover & Active Cards):** Lifted state upon hover or active selection. Outline shifts to `#D6DDE7`. Shadow: `0px 4px 12px rgba(30, 34, 43, 0.06), 0px 12px 24px rgba(30, 34, 43, 0.03)`. Transform: `translateY(-2px)`.
4. **Tier 3 (Modals, Overlays, Dropdowns):** Solid `#FFFFFF` or elevated card. Shadow: `0px 12px 32px rgba(30, 34, 43, 0.10), 0px 2px 6px rgba(30, 34, 43, 0.04)`.
5. **Tier Glass (Floating Navigation, Action Bars, Sticky Headers):** Background `rgba(255, 255, 255, 0.82)` with `backdrop-filter: blur(12px) saturate(160%)`. Bounded by a 1px border in `rgba(232, 236, 242, 0.8)`. Shadow: `0px 4px 20px rgba(0, 0, 0, 0.03)`.

## Shapes

The design system employs a calibrated corner language ranging strictly between 8px and 12px to convey modern polish while retaining structural authority.

- **Small Components (8px - `rounded-base`):** Form inputs, buttons, search bars, pill chips, table rows, and alert banners.
- **Medium Components (12px - `rounded-lg`):** Standard data cards, metric summary blocks, sparkline containers, and bottom sheets.
- **Large Modals & Surfaces (16px - `rounded-xl`):** Primary modal dialogs, KYC flow frames, and complete drawer sheets.
- **Circular Elements (Fully Rounded / 9999px):** Status indicators, active presence dots, icon badges, and avatar frames.

## Components

### Buttons
- **Primary:** Background `#00D09C`, text `#FFFFFF` (or `#1E222B` on large display CTAs), border radius 8px, font weight 600. Hover: `#00B386`. Active: `#009E75`. Focused state features an offset 2px ring of `#00D09C` at 30% opacity.
- **Secondary / Outline:** Background `transparent`, border 1px solid `#E8ECF2`, text `#1E222B`. Hover: background `#F7F9FB`, border `#D6DDE7`.
- **AI Signal Variant:** Background `#5367FF`, text `#FFFFFF`. Hover: `#4153E0`. Used specifically for automated actions, smart rebalancing, and algorithmic filters.
- **Destructive:** Background `rgba(235, 87, 87, 0.10)`, text `#EB5757`, border 1px solid `rgba(235, 87, 87, 0.20)`. Hover: Background `#EB5757`, text `#FFFFFF`.

### High-Density Metric Cards
- Surface `#FFFFFF`, border 1px solid `#E8ECF2`, radius 12px, padding 16px to 20px.
- **Header:** Label in `body-sm` (`#44475B`) paired with an optional 16px contextual information tooltip icon (`#7E8597`).
- **Value:** Displayed in `numeric-metric-lg` (`#1E222B`), tabular numbers.
- **Footer Delta:** Tag or inline pill featuring a directional arrow (`↑` or `↓`), percentage delta, and duration context (e.g., `+2.45% 1D`). Positive values use `#00D09C` with `rgba(0, 208, 156, 0.12)` background; negative values use `#EB5757` with `rgba(235, 87, 87, 0.12)` background.

### Sparklines & Micro-Charts
- Integrated inside metric cards and table rows without axis lines or grid noise.
- Vector path width: 2px. Filled area under curve uses a vertical linear gradient transitioning from 15% opacity of the line color at the peak to 0% at baseline.
- Positive trends use `#00D09C`; negative trends use `#EB5757`.

### Chips & Badges
- Height: 24px (compact) or 28px (default), radius 9999px (full pill) or 6px (tag).
- **Positive:** Background `rgba(0, 208, 156, 0.10)`, text `#00B386`, border 1px solid `rgba(0, 208, 156, 0.25)`.
- **Neutral / Amber:** Background `rgba(255, 176, 32, 0.10)`, text `#C88400`, border 1px solid `rgba(255, 176, 32, 0.25)`.
- **Critical:** Background `rgba(235, 87, 87, 0.10)`, text `#EB5757`, border 1px solid `rgba(235, 87, 87, 0.25)`.
- **AI Signal:** Background `rgba(83, 103, 255, 0.10)`, text `#5367FF`, border 1px solid `rgba(83, 103, 255, 0.25)`.

### Form Inputs & Order Fields
- Background `#FFFFFF`, height 44px, border 1px solid `#E8ECF2`, radius 8px, text `#1E222B`, placeholder `#7E8597`.
- **Focus:** Border color `#00D09C`, box-shadow `0px 0px 0px 3px rgba(0, 208, 156, 0.15)`.
- **Numeric Stepper / Order Amount:** Includes currency symbol fixed prefix (`#44475B`) and tabular large numeric values with real-time balance calculations displayed beneath.

### Checkboxes & Radio Buttons
- 18px box size, 4px border radius for checkboxes, full circle for radios.
- Unselected: Border 1.5px solid `#D6DDE7`, background `#FFFFFF`.
- Selected: Border `#00D09C`, background `#00D09C`, inner icon pure white.

### Data Tables & Asset Lists
- Rows have fixed height (56px standard, 48px dense).
- Row border-bottom: 1px solid `#F0F3F7`. Hover background: `#F7F9FB`.
- Asset columns feature a 36px icon container with a 4-point rounded corner, paired with a two-line text layout: primary symbol/name (`title-md` in `#1E222B`) over sub-sector or ticker code (`body-sm` in `#7E8597`).
